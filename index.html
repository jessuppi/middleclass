Classless-first CSS for static websites

Good defaults, minimal markup.

StyleWire gives semantic HTML a clean, responsive foundation while keeping layout and component classes small and predictable.

Principles

Semantic first

Plain headings, paragraphs, links, lists, tables, and forms look intentional without extra classes.

No build step

Link one CSS file from a static page. There is no package manager, preprocessor, or JavaScript dependency.

Easy to override

Public custom properties control the colors, spacing, widths, typography, and component shape.

Components

StyleWire adds only a few classes where semantic HTML cannot express layout or presentation by itself.

Card

Use .card for a contained section with a subtle surface and border.

Continue to forms

Buttons

Native buttons and submit inputs share the same base style. Links can opt in with .button.

Secondary
Small public API. Layout uses .container, .reading-width, .stack, .cluster, and .columns.
Why classless-first instead of completely classless?

Semantic selectors can style content safely, but they cannot infer whether a group should become columns, a cluster, or a card. A few explicit classes keep those choices understandable.

Content elements

A framework should make the common path easy without making custom work difficult.

Inline code, keyboard input such as Ctrl + S, highlighted text, and ordinary links receive useful defaults.
