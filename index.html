MiddleClass 0.2.0

Good defaults, minimal markup.

MiddleClass gives semantic HTML a clean, responsive foundation while keeping layout and component classes small and predictable.

Download CSS Installation Browse the repository

Installation

Copy the single stylesheet into your project and link it from the document head. There is no build step, package manager, or JavaScript dependency.

<link rel="stylesheet" href="/assets/middleclass.css">

Principles

Semantic first

Plain headings, paragraphs, links, lists, tables, and forms look intentional without extra classes.

No build step

Link one CSS file from a static page. There is no package manager, preprocessor, or JavaScript dependency.

Easy to override

Public custom properties control colors, spacing, widths, typography, and component shape.

Components

MiddleClass adds classes only where semantic HTML cannot express layout or presentation by itself.

Card

Use .card for a contained section with a subtle surface and border.

Why classless-first instead of completely classless?

Semantic selectors can style content safely, but they cannot infer whether a group should become columns, a cluster, or a card. A few explicit classes keep those choices understandable.
