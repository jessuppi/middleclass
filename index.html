MiddleClass 0.2.0

Good defaults, minimal markup.

MiddleClass gives semantic HTML a clean, responsive foundation while keeping layout and component classes small and predictable.

Download CSS Installation Browse the repository

Installation

Copy the single stylesheet into your project and link it from the document head. There is no build step, package manager, or JavaScript dependency.

<link rel="stylesheet" href="/assets/middleclass.css">

Principles

Semantic first

Plain headings, paragraphs, links, lists, tables, forms, and disclosures look intentional without extra classes.

No build step

Link one readable CSS file from a static page. There is no package manager, preprocessor, or JavaScript dependency.

Easy to override

Public custom properties control typography, widths, spacing, colors, and component-specific presentation.

Why classless-first instead of completely classless?

Semantic selectors can style content safely, but they cannot infer whether a group should become columns, a cluster, a card, or an overlaid dropdown menu. A few explicit classes keep those choices understandable.

A framework should make the common path easy without making custom work difficult.
